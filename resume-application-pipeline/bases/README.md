# Resume category templates

Every content.py here is a **synthetic example**, not a real applicant resume. Replace all details with verified facts before use. The original personal template PDFs, work history and metrics are excluded.

Categories: general, ai-agent, fullstack-product, backend-platform, enterprise-java, data-cloud, infra-systems, embedded, cpp-systems, fde, ml-gpu, intern. Choose by the role's actual responsibilities. Each preserves the original CONTENT tuple structure for the renderer and autofill converter.

Run `python tools/create_example_template.py`, then `python tools/build_library.py --docx-only` to generate sample documents locally. PDF conversion uses Microsoft Word on macOS. The legacy variant labels Dec2026 and May2027 are demonstration values; configure actual confirmed dates consistently in the variant parser and CONTENT before production use.
