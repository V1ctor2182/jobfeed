# Technical keyword taxonomy

Classify terms from a job description before editing a resume. Include only skills the applicant can truthfully claim; a keyword match is not evidence of experience.

- Languages: Python, Java, JavaScript, TypeScript, C, C++, C#, Go, Rust, SQL, Bash.
- Frameworks: React, Next.js, Node.js, FastAPI, Django, Spring Boot, .NET.
- Data systems: PostgreSQL, MySQL, SQLite, Redis, Kafka, vector databases.
- Cloud and delivery: AWS, Azure, GCP, Docker, Kubernetes, Terraform, CI/CD.
- AI and ML: PyTorch, scikit-learn, model evaluation, embeddings, RAG, tool calling.
- Systems and embedded: Linux, RTOS, CAN, firmware, networking, concurrency.
- Named standards and protocols may count when relevant and supported.

Soft skills, personality adjectives, generic process phrases and interview topics are not technical keywords. Treat alternate requirements as alternatives. Record unsupported requirements as gaps. Tie every achievement and number to a verified source; do not invent metrics to improve a match.

The original applicant-specific keyword case studies are intentionally omitted.
